# Multi-Agent Graph Design & State Machine

This document details the state definitions, conditional routing rules, and individual roles of the **12 cooperative/competitive agents** that orchestrate within the TradingAgents LangGraph workflow.

---

## 📊 Shared State Schema

TradingAgents models its workflow state on a unified LangGraph `MessagesState` called `AgentState`, augmented with structured report strings, nested team states, and historical trade contexts.

### 1. `AgentState` Definition
Located in `tradingagents/agents/utils/agent_states.py`, `AgentState` is defined as:

```python
class AgentState(MessagesState):
    company_of_interest: Annotated[str, "Company that we are interested in trading"]
    asset_type: Annotated[str, "Asset type under analysis such as stock or crypto"]
    instrument_context: Annotated[str, "Deterministic ticker identity resolved at run start"]
    trade_date: Annotated[str, "What date we are trading at"]
    sender: Annotated[str, "Agent that sent this message"]

    # Factual Analyst Reports
    market_report: Annotated[str, "Report from the Market Analyst"]
    sentiment_report: Annotated[str, "Report from the Sentiment Analyst"]
    news_report: Annotated[str, "Report from the News Researcher of current world affairs"]
    fundamentals_report: Annotated[str, "Report from the Fundamentals Researcher"]

    # Research Team Debate Nested State
    investment_debate_state: Annotated[InvestDebateState, "Current state of the debate on if to invest or not"]
    investment_plan: Annotated[str, "Plan generated by the Analyst"]

    # Trading Proposal State
    trader_investment_plan: Annotated[str, "Plan generated by the Trader"]

    # Risk Management Team Debate Nested State
    risk_debate_state: Annotated[RiskDebateState, "Current state of the debate on evaluating risk"]
    final_trade_decision: Annotated[str, "Final decision made by the Risk Analysts"]

    # Dynamic Contexts
    past_context: Annotated[str, "Memory log context injected at run start (same-ticker decisions + cross-ticker lessons)"]
    portfolio_context: Annotated[str, "Caller-supplied holdings and cash, rendered at run start; empty when not provided"]
```

### 2. Nested Team States (`InvestDebateState` & `RiskDebateState`)
To maintain local debate threads without polluting the primary message queue:

*   **`InvestDebateState`:**
    *   `bull_history`: Complete bearish-response history.
    *   `bear_history`: Complete bullish-response history.
    *   `history`: Combined conversational log.
    *   `current_response`: The latest response to keep round-robin turn-taking updated.
    *   `judge_decision`: Final decision/scoring by the referee.
    *   `count`: Integer tracking the exact turn count.
*   **`RiskDebateState`:**
    *   `aggressive_history` / `conservative_history` / `neutral_history`: Separate individual argument logs.
    *   `history`: Aggregated risk discussion.
    *   `latest_speaker`: String identifying who spoke last.
    *   `current_aggressive_response` / `current_conservative_response` / `current_neutral_response`: Individual latest turn responses.
    *   `judge_decision`: Final risk and sizing verdict.
    *   `count`: Sizing loop turn counter.

## 🗺️ Graph Topology

The execution topology is a structured, acyclic-to-cyclic hybrid. The flow passes through four distinct phases:

```
[START]
   │
   ▼
┌─────────────────────────┐
│ Phase 1: Analysts       │◄───────┐ (Tool-Calling Loop)
│ Market -> Sentiment    │────────┘ (For each Analyst node)
│ -> News -> Fundamentals │
└──────────┬──────────────┘
           │ (Wipe conversation, save reports, anchor context)
           ▼
┌─────────────────────────┐
│ Phase 2: Research       │◄───────┐ (Turn-Based Cycle)
│ Bull vs. Bear           │────────┘ (Bull <-> Bear)
│ Moderated by RM         │
└──────────┬──────────────┘
           │ (Generate Structured ResearchPlan)
           ▼
┌─────────────────────────┐
│ Phase 3: Trading        │
│ Trader                  │ (Formulate Transaction Proposal)
└──────────┬──────────────┘
           │ (Generate Structured TraderProposal)
           ▼
┌─────────────────────────┐
│ Phase 4: Sizing & Risk  │◄───────┐ (Turn-Based Cycle)
│ Aggressive vs. Conserv. │────────┘ (Aggressive -> Conservative -> Neutral)
│ vs. Neutral             │
│ Moderated by PM         │
└──────────┬──────────────┘
           │ (Generate Structured PortfolioDecision)
           ▼
 [END]
```

## 👥 Detailed Agent Specifications

### Phase 1: Sequential Analysts (Objective)
These 4 agents are responsible for extracting empirical evidence. They employ tool-calling capabilities to query the data ingest interfaces.

1.  **Market Analyst (`create_market_analyst`)**
    *   **Focus:** Core price momentum and technical levels.
    *   **Tools:** `get_stock_data`, `get_indicators` (e.g., Simple/Exponential Moving Averages, RSI, MACD, Bollinger Bands).
    *   **Deliverable:** Fills `market_report` in the shared state.
2.  **Sentiment Analyst (`create_sentiment_analyst`)**
    *   **Focus:** Social trends and crowd wisdom.
    *   **Tools:** `get_news`, `get_prediction_markets` (Polymarket), Reddit/Stocktwits feeds.
    *   **Deliverable:** Outputs a structured `SentimentReport` Pydantic model parsed into `sentiment_report` in the shared state, mapping score (0-10) and confidence.
3.  **News Analyst (`create_news_analyst`)**
    *   **Focus:** Catalysts, corporate events, macro factors, and executive actions.
    *   **Tools:** `get_news`, `get_global_news`, `get_insider_transactions`, `get_macro_indicators` (FRED).
    *   **Deliverable:** Fills `news_report` in the shared state.
4.  **Fundamentals Analyst (`create_fundamentals_analyst`)**
    *   **Focus:** Financial health, solvency, and cashflow.
    *   **Tools:** `get_fundamentals`, `get_balance_sheet`, `get_cashflow`, `get_income_statement`.
    *   **Deliverable:** Fills `fundamentals_report` in the shared state.

### Phase 2: Research Team (Subjective Debate)
These nodes do not have direct access to tools. They evaluate the reports produced in Phase 1.

5.  **Bull Researcher (`create_bear_researcher`)**
    *   **Focus:** Generates the strongest possible investment/long thesis. Integrates positive developments across technical, sentiment, news, and fundamental dimensions.
6.  **Bear Researcher (`create_bear_researcher`)**
    *   **Focus:** Generates the strongest possible risk/sell/short thesis, identifying weaknesses, valuation limits, macro headwinds, and structural obstacles.
7.  **Research Manager (`create_research_manager`)**
    *   **Focus:** Referees the Bull vs. Bear debate. Scores the validity of arguments, chooses which thesis carries the consensus, and outputs a structured `ResearchPlan` (Buy/Overweight/Hold/Underweight/Sell rating).

### Phase 3: Trading Desk (Tactical Structuring)
8.  **Trader (`create_trader`)**
    *   **Focus:** Translates the Research Manager's core thesis into a tactical trade entry.
    *   **Deliverable:** Formulates the structured `TraderProposal` mapping transaction action (Buy/Hold/Sell), entry targets, stop-loss limits, and sizing suggestions.

### Phase 4: Sizing & Risk Management (Sizing Debate)
These nodes debate portfolio risk and capital allocation based on the trader's tactical proposal.

9.  **Aggressive Analyst (`create_aggressive_debator`)**
    *   **Focus:** Advocates for maximizing capital return, capture speed, and expanding exposure limits.
10. **Conservative Analyst (`create_conservative_debator`)**
    *   **Focus:** Advocates for risk boundaries, capital preservation, deep safety margins, and trailing stop protections.
11. **Neutral Analyst (`create_neutral_debator`)**
    *   **Focus:** Weighs probabilistic averages, risk/reward ratios, and balanced exposure targets.
12. **Portfolio Manager (`create_portfolio_manager`)**
    *   **Focus:** Resolves the three-way risk debate. Integrates caller account parameters (`portfolio_context`), commits to the structured `PortfolioDecision`, and triggers the end of the graph execution.

## 🛠️ Graph Flow & Transitions

### 1. Conversational History Wipe (`create_msg_delete`)
To prevent LLM token fatigue and attention dispersion across different analyst roles, transitions between sequential analysts trigger a context-window wipe.

The deletion is implemented via LangGraph's message deletion mechanism:
```python
def create_msg_delete():
    def delete_messages(state):
        messages = state["messages"]
        removal_operations = [RemoveMessage(id=m.id) for m in messages]

        # To prevent models treating a bare "Continue" as the task, we anchor the 
        # placeholder with resolved ticker and trade date
        instrument_context = get_instrument_context_from_state(state)
        trade_date = state.get("trade_date", "the requested date")
        placeholder = HumanMessage(
            content=(
                f"Proceed with your assigned analysis for this workflow. "
                f"{instrument_context} The analysis date is {trade_date}."
            )
        )
        return {"messages": removal_operations + [placeholder]}
    return delete_messages
```

### 2. Turn-Based Routing Rules
Transitions are driven by `ConditionalLogic` (defined in `tradingagents/graph/conditional_logic.py`):

*   **Analyst Tool Loops:**
    ```python
    def should_continue_market(self, state: AgentState):
        messages = state["messages"]
        last_message = messages[-1]
        if last_message.tool_calls:
            return "tools_market"
        return "Msg Clear Market"
    ```
*   **Research Debate Routing:**
    ```python
    def should_continue_debate(self, state: AgentState) -> str:
        if state["investment_debate_state"]["count"] >= 2 * self.max_debate_rounds:
            return "Research Manager"
        if state["investment_debate_state"]["current_response"].startswith("Bull"):
            return "Bear Researcher"
        return "Bull Researcher"
    ```
*   **Risk Debate Routing:**
    ```python
    def should_continue_risk_analysis(self, state: AgentState) -> str:
        if state["risk_debate_state"]["count"] >= 3 * self.max_risk_discuss_rounds:
            return "Portfolio Manager"
        if state["risk_debate_state"]["latest_speaker"].startswith("Aggressive"):
            return "Conservative Analyst"
        if state["risk_debate_state"]["latest_speaker"].startswith("Conservative"):
            return "Neutral Analyst"
        return "Aggressive Analyst"
    ```
